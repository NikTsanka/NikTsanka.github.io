# ლარის კურსი — LarisKursi

საქართველოს ეროვნული ბანკის ოფიციალური ვალუტის კურსების საიტი: ლარის კალკულატორი,
დღევანდელი კურსების ცხრილი, ისტორიული გრაფიკები და კურსის შეტყობინებები.

სუფთა HTML + CSS + vanilla JS. build step არ სჭირდება — უბრალოდ გახსენით `index.html`.
ერთადერთი გარე ბიბლიოთეკა Chart.js-ია, რომელიც CDN-იდან იტვირთება მხოლოდ მაშინ,
როცა გრაფიკის სექცია ეკრანზე გამოჩნდება.

---

## გაშვება

```
# უბრალოდ ორმაგი დაწკაპუნება index.html-ზე
# ან ლოკალური სერვერით (რეკომენდებულია — clipboard და manifest სრულად მუშაობს):
npx serve .
python -m http.server 8000
```

## API

```
დღევანდელი:   https://nbg.gov.ge/gw/api/ct/monetarypolicy/currencies/{ka|en}/json
ისტორიული:    https://nbg.gov.ge/gw/api/ct/monetarypolicy/currencies/{ka|en}/json/?date=YYYY-MM-DD
```

- API ერთ მოთხოვნაზე **ერთ დღეს** აბრუნებს — პერიოდს არ იღებს. გრაფიკი ითხოვს
  შერჩეულ თარიღებს პარალელურად, პატარა batch-ებად (7 დღე — ყოველდღიური წერტილები,
  1 თვე — ყოველ მე-2 დღეს, 6 თვე / 1 წელი — კვირეული).
- ყველა პასუხი ინახება `localStorage`-ში თარიღის მიხედვით, ამიტომ ერთი დღე ორჯერ არასდროს ითხოვება.
- შაბათ-კვირას და უქმეებზე NBG აბრუნებს წინა სამუშაო დღეს — კოდი შედეგებს
  ფაქტობრივი თარიღით აჯგუფებს და იმეორებებს შლის.
- `rate` მოცემულია `quantity` ერთეულზე (მაგ. AMD — 1000-ზე), ამიტომ ყველგან
  გამოიყენება `rate / quantity`.
- ორი უცხოური ვალუტის კონვერტაცია ყოველთვის ლარზე გადის:
  `amount × unitRate(from) ÷ unitRate(to)`.
- **CORS:** NBG ამჟამად აბრუნებს `Access-Control-Allow-Origin: *`, ამიტომ პროქსი არ სჭირდება.
  თუ ოდესმე CORS შეცდომა გამოჩნდა, `js/api.js`-ში შეავსეთ `PROXY_PREFIX`.

## გამოქვეყნება

საიტი გამოქვეყნებულია GitHub Pages-ზე: **https://niktsanka.github.io/lariskursi/**

- canonical, `og:url`, JSON-LD და `sitemap.xml` ამ მისამართზეა დაყენებული.
- `og-image.png` (1200×630) სოციალური გაზიარებისთვის უკვე დამატებულია.
- `robots.txt` რეპოს **ძირშია** (`/robots.txt`) — ქვესაქაღალდეში მას crawler-ები
  არ კითხულობენ; იქიდან მიუთითებს ამ sitemap-ზე.

თუ საიტი ოდესმე საკუთარ დომენზე გადავა, განახლდეს: `index.html`-ში canonical / `og:url` /
JSON-LD, `sitemap.xml` და რეპოს ძირის `robots.txt`.

## შენიშვნები

- **დროშები:** Windows-ს არ აქვს ქვეყნების emoji დროშები, ამიტომ `calculator.js`
  canvas-ით ამოწმებს მხარდაჭერას და მის გარეშე აჩვენებს ორასოიან ქვეყნის ბეიჯს.
- **თარიღები:** ზოგიერთ ბრაუზერს არ აქვს `ka` ICU მონაცემები და `Intl`-ს ინგლისურზე
  გადააქვს — ქართული თვეები `i18n.js`-შია ჩაწერილი.
- **მონაცემები ბრაუზერში:** თემა (`lk:theme`), ენა (`lk:lang`), ბოლო წყვილი (`lk:pair`),
  შეტყობინებები (`lk:alerts`), კურსების ქეში (`lk:latest:*`, `lk:hist:*`).
  არაფერი იგზავნება სერვერზე.
